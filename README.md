# Documento Confidencial de Cultos Paranormais // Ordo Veritatis

Este projeto é um documento oficial, contínuo e confidencial desenvolvido para o seu RPG de mesa no universo da **Ordo Veritatis**.

---

## 📁 Estrutura de Arquivos

- [index.html](file:///c:/Users/User/OneDrive/Documentos/Antigravity/Liturgie/Cultos/index.html) — O documento completo, diagramado como um relatório de inteligência confidencial de leitura contínua.
- [style.css](file:///c:/Users/User/OneDrive/Documentos/Antigravity/Liturgie/Cultos/style.css) — Estilo profissional rigorosamente monocromático (preto e branco), tipografia formal e formato de dossiê.
- `images/` — Diretório principal com todos os dossiês e imagens de líderes/membros em formato `.jpeg` e `.jpg` (otimizado para compatibilidade com GitHub Pages).
- `assets/` — Cópia espelhada dos recursos e insígnias para redundância e resiliência de caminhos.
- [cults-data.js](file:///c:/Users/User/OneDrive/Documentos/Antigravity/Liturgie/Cultos/cults-data.js) — Base de dados em formato de script caso queira reaproveitar ou consultar.
